# Ask Your Data

A minimal CSV analytics app: upload one CSV, get a data-derived summary, ask questions in plain English, and see real SQL and result rows. A simple chart may be added after the core workflow works.

## Current status
Planning scaffold only. Documentation is not proof that the application is implemented.

## Documents
- `CLAUDE.md` — coding and milestone rules.
- `PRD.md` — minimal product scope, including dataset summaries.
- `ARCHITECTURE.md` — proposed technical flow.
- `TASKS.md` — implementation milestones.
- `DESIGN.md` — lightweight frontend design.
- `.gitignore` — excludes secrets, local environments, and data.

## Security
Never commit API keys, `.env` files, or private uploaded datasets.
